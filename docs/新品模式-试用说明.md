# 新品模式：完整应用试用版

入口：项目根目录 `一键启动.cmd`。启动完整GVPAK Studio，不是单独的模块页。

## 本次已接入

- 原有项目管理、编辑、生成、导出、设置和本地处理入口保留。
- 生成图片 → 新品套图：选择素材文件夹或拖入原图，填写要求，默认实时并发3，可切异步批量。
- 手动用途：先选白底图/场景图/真人模特/爆炸图，再点缩略图；同图可多选。方框从内到外固定为白底→场景→真人→爆炸。
- 自动识别采用Gemini 3.8 Flash，生图采用Nano Banana 2.1；使用主机已有Google API配置。
- 空内托是否加膏体、爆炸图部件证据不足等先集中澄清；可以选择参考图或跳过爆炸图。
- 外观保持/定向改款，选择可变部件；改款先生成白底设计锚点，再统一后续外观。
- 一行数量/费用确认；独立任务提示词、多参考图、后台任务恢复、结果文件夹保存及整套ZIP下载。
- 编辑 → 旋转与翻转 → 主体自动摆正：本机OpenCV识别主体倾斜，纠正小角度，生成新版本，保留原图。±90°手动旋转继续保留。

## 启动检查

`一键启动.cmd → start.cmd → start.ps1` 已实际执行并验证。启动器先找到能在Python隔离模式下导入cv2的解释器，再启动完整应用，检查新品接口和OpenCV，检查通过后打开浏览器。

当前后端实际OpenCV版本为4.8.0；普通Python环境另有5.0.0，后端以`-I`隔离模式的实际检测值为准。无需安装新依赖。

## 验证与边界

- 新品前端逻辑9项、完整应用交互5组通过；交互测试使用隔离模型夹具，不是对真实成图质量的声明。
- 后端原有和新品回归64项通过，另有真实OpenCV后端集成测试通过。
- 本地OpenCV对−19°、7°、31°，纯色/双色背景共6张合成图纠偏通过，剩余角度均小于2°。
- Google密钥配置状态已检测到；本次没有代替用户调用付费识别/生图，真实产品成图由用户点击试用验收。
- 复杂多主体、遮挡严重或主体与背景无法可靠分离时，摆正会报错而不是胡乱旋转；不会把透视侧面变成正面。
- 生成期间请勿修改本批输入图片版本；输入改变时任务会停止采用变化后的参考，避免套图身份不一致。
- 本版优先验证新品功能，P4清单保留在4.3，不把本次试用记作4.4–4.11已完成。

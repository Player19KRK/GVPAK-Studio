# 2026-10-23 使用体验更新

## 本轮任务

1. 移除项目图片总数、任务图片数量和排队请求数量上限。大批导入自动分段传输；单张 30 MB、单次传输 80 MiB 的资源边界保留。文件夹遍历深度保留防循环限制。
2. 中文界面采用 ASD-STE100 的清晰表达原则：使用直接动作、统一术语、明确错误后的操作。属于中文适配，不声称是英语规范认证。
3. 同事端的“本机保存文件夹”调用浏览器目录选择器。Chrome/Edge 需可信 HTTPS。目录权限仅存在同事浏览器，主机看不到其磁盘路径。本次页面打开期间，新结果自动保存；刷新后需重新选择。取消目录选择不会启动写入。不支持目录选择时，明确回退到浏览器下载。
4. 图片浏览区支持按住鼠标左右拖动，小幅移动仍按单击处理。
5. 每张任务图片显示阶段进度；供应商等待阶段为不定进度，不编造百分比。
6. 处理页支持逐图勾选、全选和取消全选；主动取消全部后处理范围为空。
7. 项目删除移入 deleted-projects，可通过撤销恢复。活动任务所在项目不能删除。
8. 实时生成逐张调用生图接口，结果持久化后进入下一张；异步生成使用 Google Batch。Poe 的异步模式使用主机队列，不使用 Google Batch，不声称半价。网络结果未知时标为待检查，不自动重复付费请求。
9. 原 Mark read 改为“关闭完成提醒”，只关闭提醒，不删除图片；成功后按钮消失。
10. 下载支持 exports 下的任务子目录，保持账号隔离、路径校验和真实文件扩展名。
11. 增加 Poe GPT-Image-2.5-Flare 与 GPT-Image-2.5-Sunburst；主机设置 Poe API 密钥。同事只能查询是否配置，不能读取或修改密钥。使用官方 chat/completions、stream=false；媒体只从受限 Poe CDN 地址读取。未执行付费供应商端到端测试。
12. 同事端显示可拖动的圆形盾牌问题反馈按钮。支持粘贴和拖入多张截图，文字位于图片下方。提交后保存在“问题汇总/账号/时间-编号”。图片解码后重新保存为 PNG，文件名由服务端生成。反馈目录不进入 Git 或压缩包。

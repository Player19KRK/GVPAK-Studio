# 本机测试版本说明

2026-10-28。当前版本已覆盖正式应用目录，保留现有项目和配置。4.11 与 P5.2/5.3/5.4/5.6/5.7 已完成；P5.1/5.5 的真实 Windows 外部目录验收尚未完成，不能作为全量验收通过版本签收。证据与阻塞条件见 p5-finalization-progress.md。

## 启动
双击仓库根目录“一键启动.cmd”，等待检查完成，浏览器打开 http://127.0.0.1:8787/。启动链检查本机 OpenCV 和新品模块。此机使用已安装的 Python 3.10/OpenCV 4.8.0，无需额外启动本地像素处理服务。当前服务已运行，可直接打开上述地址；已打开的旧页面刷新一次取得新版资源。

这是当前机器的完整应用目录，未将用户项目、密钥或证书打入可外发压缩包，也未改动远端仓库。

## 新品套图
1. 顶部“生成图片”进入“新品套图”，选择素材文件夹或拖入原始图片。
2. 默认自动分配；指定用途时，先点白底图、场景图、真人模特或爆炸图按钮，再点对应缩略图。可以一图多用途，白底边框在最内层。
3. 填写产品事实和文字要求。演示的已知结构为塑料外壳、湿压纸浆内托、旋转推出；外观保持/改款及允许改动部位由选项控制。
4. 旁边选择比例、⇄、分辨率、实时/异步和并行数；默认实时。
5. 点“识别并生成套图”。遇到内容或参考图不明确，先在页面回答；费用/数量门槛在原行继续。手动检查任务单可使用“仅识别并制作任务单”，之后主按钮显示“确认任务单并生成”。
6. 结果逐张出现，可停止后续提交并保留已返回结果；“下载整套 ZIP”取得图片和任务单。配置读取失败可原地重试。

## 本地编辑
“主体自动摆正”检测画面中主体的二维倾斜角度并旋转纠正，已经用约 12° 的实际像素输入验到 0°；它不重建产品的三维拍摄视角。处理结果生成新版本，Ctrl+Z 可撤销，原图保留。

键盘主流程：Tab 到素材，Space 选中，Ctrl+K 输入处理要求，Enter 执行，Tab 离开输入框后 Ctrl+Z 撤销。输入框内 Ctrl+Z 遵守文本编辑习惯。coverflow 原版空格快选等操作继续保留。

## 验收范围
模拟生成结果只证明任务、澄清和下载交互，不冒充这批产品的实际供应商成图质量。本轮没有新增付费图像生成。真实 Windows 目录的自动写回和关闭重开仍须完成；OPFS 及后端磁盘字节测试已通过，两个范围分别记录。

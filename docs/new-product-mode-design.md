# 新品模式：提示词模板与任务逻辑 v1

日期：2026-10-27。范围：优先开发可试用的“生成图片 → 新品套图”，P4清单保留在4.3，不把本功能冒记为4.4以后完成。

## 用户已经确定的演示事实

- 产品是可替换香体膏包装，塑料壳体、湿压纸浆模塑内托、旋转推出膏体。
- 需要多角度白底、对应成品的简洁高级静物摄影、欧美成年模特手持/使用场景，以及爆炸图。
- 视觉：北欧、干净简约、高级、自然摄影，Sony A7R III摄影语言。
- 选择素材文件夹或拖入原图，补充文字要求，默认实时；可切异步，并行优先。
- 模型不理解产品时可以询问。例如空纸塑内托是否要加入膏体。该澄清由用户本次明确允许，只用于新品流程；不使用alert/confirm。
- 用户尚未指定是否改款、哪些部件改款，默认保持外观；具体变更在表单里明确选择。
- 用户提供的是18张缩略图的总览截图，用于设计案例，不把整张截图冒充18张原始参考图。

## 1. 正常操作路径

选择/拖入原图 → 本地精确去重与导入 → Gemini看图识别 → 必要时集中澄清 → 生成任务单 → 费用/数量门槛一行确认 → 并行生成 → 自动保存结果与任务单。

主要按钮“识别并生成套图”；无需逐张指定提示词。另提供“仅制作任务单”，方便先核对自动参考图分配、修改任务、导出JSON。

没有歧义时不增加人为审批步骤；有歧义时显示显著的内联问题区。一次按产品合并询问，答案应用到所有相关任务。

## 2. 两阶段模型职责

- Gemini 3.8 Flash（`gemini-3.8-flash`）：看到带素材ID标记的真实照片，返回结构化识别、去重候选、产品部件、角度、推荐参考图、场景建议与问题。
- Nano Banana 2.1（`gemini-nano-banana-2.1`）：根据每条任务的独立提示词及多张参考图生成图片。
- 提示词由固定模板、视觉识别证据、用户文字、澄清答案和外观变更白名单共同构成；不让模型任意改写产品事实。
- 不把DeepSeek接入此流程。发给后端的素材选择上下文仍为SelectionContext，文件名不带路径。
- 官方模型及请求限制核验见 `new-product-model-research.md`。

## 3. 图像识别与去重

1. SHA-256相同：合并为同一素材，不重复上传，不再重复看图；保留文件名来源，不删除原文件。
2. Gemini相似去重：仅同一产品、同一部件、同一开合/装配状态、几乎相同角度且高置信度时合并任务用途。
3. 不把“正面和侧面”“空托和装膏体”“闭盖和开盖”“纸浆内托和塑料壳体”视作重复。
4. 置信不足保留两张，标成待判断；任务参考图可手动改选，重复候选可重新纳入。
5. 首版单次最多40张不同原图；不会静默截断。超过20张看图按既有数量门槛先确认。
6. 识别图片压缩到适合看图的尺寸；按实际base64后JSON体积控制在官方inline请求上限之内。生图参考图另用更清晰版本。

每张图识别：产品组ID、部件角色、视角、开合状态、是否有内容物、清晰度、是否完整、可用于哪些任务、重复候选及理由。所有引用ID必须来自输入；本地再次校验。

## 4. 演示素材的参考图规则

| 输入证据 | 可支持任务 | 不能据此推断 |
| --- | --- | --- |
| 完整闭合壳体、多角度壳体 | 成品白底、静物主图、模特手持 | 内部零件和膏体已经存在 |
| 开盖、手持旋转演示 | 开盖构图、手持方式、推出动作线索 | 看不清的螺纹/齿轮、准确旋转方向 |
| 空纸塑替换装/内托 | 纸浆纹理、替换装结构与形状 | 自动加入膏体或把纸浆渲染成塑料 |
| 拆开陈列/部件图 | 爆炸图部件与装配顺序证据 | 不可见的隐藏机构或额外零件 |

自动场景参考优先：完整成品主图 → 补充侧/开盖角度 → 必要材质细节。模特参考优先：完整成品+手持/使用线索；没有膏体时采用手持展示，不画空包装直接涂抹皮肤。爆炸图优先：部件全貌+装配线索，证据不够则提问并允许指定参考图。

## 5. 澄清问题

问题结构：`id / productId / kind / question / options / affectedKinds / assetIds / required`。

示例：

- “识别到空的香体膏替换装纸塑内托，成品图是否需要加入膏体？”→ 加入 / 保持空托 / 我来补充。
- 选择加入后可补充颜色、形状、露出高度；未给定的精确品牌/配方/机构不虚构。
- “这些部件是否已覆盖爆炸图所需的全部结构？”→ 已齐全 / 指定参考图 / 暂不生成爆炸图。
- “外观要保持原样，还是只修改指定部件？”→ 由外观表单明确，不能从“高级”一词推断重新设计。

问题没有解决时，不把依赖该答案的任务提交给生图模型。若用户明确选择跳过爆炸图，只跳过该类任务，不阻塞其余图片。

## 6. 外观变更白名单

- 默认“保持原样”：颜色、外形、部件数量、材质、纹理、标识和机构均保持。
- “定向改款”：分别选择壳体、盖子、内托、图案/品牌文字，并写明目标变化。
- 壳体颜色/表面处理、盖子颜色、图案和文字可以单独指定；未选部分锁定。
- 塑料壳体和湿压纸浆内托的材质不能互换，纸浆须保留真实纤维/湿压质感，不能因统一白色而全部变成光亮塑料。
- 改款不等于重做旋转机构；几何/结构改变需要明确说明，不从装饰变更自动推导。
- 多张图共享同一外观约束。改款时先生成一张白底设计锚点，再把该锚点加入后续任务参考图，减少不同图片各自设计。

## 7. 每条提示词的组成

```text
任务类型 + 本张构图/视角
已确认产品事实与部件材质
参考图逐张职责（主形体/角度/材质/机构证据/设计锚点）
用户原始文字要求
已回答的澄清（加入膏体/保留空托等）
外观保留或指定部件改款白名单
统一摄影风格与画面约束
本类型的禁止事项
比例、分辨率由请求参数传入，不靠提示词文字冒充设置
```

### 白底模板

忠实呈现指定参考角度与装配状态，完整产品、纯白背景、轻柔真实接触阴影、足够留边，不加道具。保留尺寸关系、标识、旋转结构和纸浆/塑料差异。用户未批准的内容物不补画。

### 静物摄影模板

北欧简洁高级产品静物摄影，柔和侧向自然光，浅暖灰/石灰白背景，少量浅木或石材支撑物与留白。Sony A7R III风格的自然色彩、真实材质、锐利主体与克制景深。不加入多余包装、促销文字、夸张反光和拥挤道具。

### 成年模特模板

欧美风格成年模特，自然仪态，简洁北欧浴室/梳妆环境，手持或展示真实比例的产品。自然手指、真实握持，不让手遮住关键结构。不把空纸塑内托当成可直接涂抹的膏体。不添加产品功效、认证或医学宣称。

### 爆炸图模板

仅将证据支持的现有部件沿真实装配轴分离排列，保持各部件数量、相对尺寸、材质和装配顺序。干净浅色背景、柔和阴影、无悬浮魔法零件，无虚构齿轮/弹簧/螺纹。膏体只有用户确认后才作为可见内容物呈现。

“Sony A7R III”是摄影风格指令，不作为真实拍摄设备或EXIF事实宣称。

## 8. 默认任务数量与设置

- 白底：每个有效且非重复的产品视角1张，部件证据图不自动各做一张。
- 高级静物：2张；成年模特手持：2张；爆炸图：1张（证据不足先问）。数量和类别可以调整。
- 比例：只用1:1 / 3:2 / 4:3 / 4:5 / 16:9，加⇄；默认1:1。
- 分辨率：1K / 2K / 4K；默认2K。实际以模型能力为准。
- 默认实时，并发3，可选1–4。异步是Google Batch，耗时可能更长，不描述为更快。

## 9. 执行图与恢复

- 保持外观：任务可独立并行。
- 定向改款：设计锚点 → 其他白底/静物/模特/爆炸图；锚点失败时不偷偷用旧外观继续。
- 异步改款可能需要锚点批次与后续批次两阶段，提示比实时慢。
- 每条任务有独立提示词和参考图列表，不把一个prompt广播给所有角度。
- 任务单和状态落盘，关闭页面后仍执行；重开恢复任务列表。
- 网络结果未确认的生图任务标记“结果待确认”，不自动重复收费重试。
- 停止只阻止新提交；已经提交的请求可能仍返回，已完成图片保留。
- 输出PNG图片及JSON任务单；原图不覆盖。可保存到已授权本机文件夹，也可一次下载整个ZIP。

## 10. 拟新增接口（等待确认）

使用现有 `POST /api/invoke/{name}` 通道，所有素材选择上下文只用SelectionContext。新品能力置于独立后端模块，旧P0–P3处理和旧generate/hybrid行为不改；不加依赖。

| 命令 | 请求 | 返回 |
| --- | --- | --- |
| `new_product_capabilities` | `{}` | 密钥是否配置、模型ID、支持尺寸/比例/模式及并发范围，不返回密钥 |
| `new_product_analyze` | `{projectId,context,brief,productFacts,appearance,approvedAnalysis}` | `{analysisId,items,products,questions,duplicateGroups,sceneIdeas}` 或看图数量门槛 |
| `new_product_start` | `{projectId,context,analysisId,answers,manifest,mode,concurrency,resolution,ratio,orientation,clientRequestId,approvedGeneration}` | `{job}` 或生图数量/费用确认行；任务引用只允许来自本次分析及本次锚点 |
| `new_product_jobs` | `{projectId?}` | 当前账号/工作区的新品任务和逐图状态、结果ID，不含主机路径 |
| `new_product_cancel` | `{jobId}` | 停止新增提交，保留已完成图片并跟踪已提交结果 |
| `new_product_result` | `{jobId,taskId}` | 校验当前工作区和任务后返回图片Blob |

`manifest.tasks[]`：`{id,kind,productId,title,prompt,referenceIds,dependsOn,enabled}`。这是用户要求的生成任务数据，不是第二份素材上下文。后端校验任务数、模型参数、引用ID、依赖、提示词长度及来源指纹。

初版不自动执行付费验证。真正Gemini识别和生图在用户试用点击后发生；测试用隔离夹具，并明确区分模拟结果和真实图片。
